# Benchline On-Job Checklist
## Arrival → closeout (print for the truck)

### Before you leave home / shop
- [ ] Confirm address + gate codes in writing
- [ ] Load tools / chemicals / PPE for THIS job only
- [ ] Charge phone + portable battery
- [ ] Estimate + change-order blank ready
- [ ] Payment method ready (reader / invoice link)

### Arrival (first 5 minutes)
- [ ] Park considerately; note truck location for customer
- [ ] Introduce yourself; confirm decision-maker on site
- [ ] Walk scope vs estimate — photograph before
- [ ] Call out anything out of scope BEFORE starting
- [ ] Confirm pets / kids / alarms

### During work
- [ ] Protect surfaces / use drop cloths
- [ ] Time-box rabbit holes; log extras on change order
- [ ] Keep work area walkable if customer is home
- [ ] If delayed >20 min past ETA window, text update

### Closeout
- [ ] Customer walkthrough — show before/after if relevant
- [ ] Collect balance OR send invoice with due-today language
- [ ] Ask for Google review (see 05-google-review-ask.md)
- [ ] Schedule follow-up / maintenance if relevant
- [ ] Photo after (with permission); note materials used

### After you leave
- [ ] Same-day thank-you SMS (04-follow-up-sms.md)
- [ ] Log job in weekly money review sheet
- [ ] Restock truck from checklist notes
