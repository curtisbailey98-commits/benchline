# Benchline Core Kit — How to use

Welcome. This kit is yours to customize. No Notion account required — every file is plain Markdown or CSV.

## What's inside

| File | Use |
|------|-----|
| 01-intake-script.md | Qualify calls & in-person leads |
| 02-estimate-template.md | Written quotes + margin rules |
| 03-job-checklist.md | Print for the truck |
| 04-follow-up-sms.md | Day-of / 24h / 7-day texts |
| 05-google-review-ask.md | Earn reviews the right way |
| 06-weekly-money-review.md | 30-min weekly money SOP |
| pricing-sheets.csv | Starting rates by trade — edit freely |

## Suggested setup (30 minutes)

1. Copy Markdown files into Notion / Obsidian / Google Docs.  
2. Import `pricing-sheets.csv` into Google Sheets or Excel; highlight your trade rows.  
3. Print `03-job-checklist.md` and laminate.  
4. Paste SMS scripts into your phone notes.  
5. Add your real Google review link to script 05.  
6. Run your first weekly money review this weekend.
