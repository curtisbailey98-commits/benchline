# Benchline Intake Script
## Solo home-service operators — phone + in-person

**Goal:** Qualify the job in under 4 minutes, set expectations, and book a clear next step.

---

### Opening (phone)

> "Hey, this is [Your Name] with [Business]. Thanks for reaching out — happy to help. Quick question so I quote you right: is this for a home or a small commercial space?"

Capture:
- Name + best callback number
- Address / neighborhood (not full access codes yet)
- Preferred window (morning / afternoon / specific day)

---

### Scope questions (adapt by trade)

1. **What needs doing?** — Let them talk 30–60 seconds. Write exact words.
2. **When did it start / last service?** — Reveals urgency and complexity.
3. **Access / pets / parking?** — Avoids day-of surprises.
4. **Anyone else quoting?** — Soft: "Totally fine if you are — I just price for quality and show-up time."
5. **Decision maker?** — "Will you be the one approving the work, or should I include someone else?"

---

### Boundary lines (use calmly)

- Out of area: "I stay inside [service radius] so I can show up on time. I can refer a trusted operator if helpful."
- Unsafe / illegal ask: "I can't take that on. Happy to help with the parts that are above board."
- Scope creep mid-call: "That's a second job. I can price it as an add-on after we finish the main one."

---

### Close

> "Based on what you described, I can send a written estimate today. If it looks good, the next open slot is [day/time]. Sound fair?"

**Never leave without:** next step + timeline + how you'll send the estimate (text / email).

---

### In-person add-ons

- Photo the problem areas (with permission).
- Confirm materials vs labor split out loud.
- Hand a one-pager or QR to your estimate form.
