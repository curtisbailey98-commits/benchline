# Benchline Weekly Money Review SOP
## 30 minutes every week — cash in / cash out / next week plan

**When:** Same day/time weekly (e.g. Sunday 6pm or Monday 7am).  
**Tools:** Bank app + pricing-sheets.csv + job log.

---

### 1. Cash in (10 min)

List every payment received this week:

| Date | Customer | Job | Method | Amount |
|------|----------|-----|--------|--------|
| | | | | |

Totals:
- Gross collected: $______
- Deposits held for future jobs: $______
- **Recognized this week:** $______

---

### 2. Cash out (10 min)

| Category | Amount |
|----------|--------|
| Materials / supplies | |
| Fuel / travel | |
| Software / ads | |
| Contractor help | |
| Owner draw (you) | |
| **Total out** | |

**Weekly profit proxy:** Recognized − Total out = $______

---

### 3. Health checks (5 min)

- [ ] Any invoice >7 days unpaid? Chase today.
- [ ] Any job under minimum margin? Note why; adjust next quote.
- [ ] Pipeline: # of booked jobs next 7 days = ____
- [ ] Emergency fund transfer this week? $____ → savings

---

### 4. Next week plan (5 min)

1. Top priority job / sale: ________________  
2. One price or process fix: ________________  
3. One marketing action (review ask, door hanger, post): ________________  

**Rule:** If profit proxy is negative two weeks in a row, pause discounting and raise minimum job.
